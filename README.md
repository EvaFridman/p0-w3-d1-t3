## Задача

Арифметические и строковые операторы иногда сами приводят типы — и `1 + '2'` даёт не то, что ждёшь. Тренируешь предсказание: сначала угадываешь результат, потом проверяешь.

```
оператор смотрит на типы и иногда приводит сам:
  1 + '2'  →  '12'   (число прилипло к строке)
  '5' - 2  →  3      (строка стала числом)
  true + 1 →  2
сначала предскажи результат, потом проверь
```

## Что нужно сделать

В `operators.js` собрать 10–12 выражений со смешанными типами (`+`, `-`, `*`, `/`, `%`, сравнения). Для каждого: сначала комментарием прогноз, затем реальный результат, пометить где ошиблась.

## Критерии приёмки

* Не меньше 10 выражений, у каждого прогноз до запуска и реальный результат.
* Есть случаи, где `+` склеивает строку, а `-`/`*` приводят строку к числу.
* В конце вывод: почему `+` ведёт себя иначе, чем остальные арифметические операторы.
